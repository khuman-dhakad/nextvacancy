# NextVacancy current web application

This directory contains the existing Next.js production application. Keep its
Vercel project and deployment root in place while parity work continues in the
separate [`apps/frontend`](../frontend) React/JavaScript app and Spring Boot
service in [`backend`](../../backend). See
[`docs/stack-migration-map.md`](../../docs/stack-migration-map.md) for current
route and service status and
[`docs/stack-migration-deployment.md`](../../docs/stack-migration-deployment.md)
for the deployment plan. The new stack is an incomplete migration and is not
the production deployment.

The current application remains a [Next.js](https://nextjs.org) project
bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
